# Games Night — centered logo correction (local only)

- All chooser logos are centred within their individual selector tiles.
- Logos in the large featured stages are also centred.
- TIDEWATER now displays a local fallback mark immediately, rather than a blank tile, when its original image is unavailable. The original TIDEWATER `public/art/logo.webp` exists in a **private** GitHub repository but is not bundled here. The fallback is newly authored text artwork, **not** a replacement or a claim that the official binary has been copied. It can be replaced once that approved binary is supplied locally.
- All original game destinations, catalogue entries and music remain unchanged.
- The revision is a local preview; GitHub and Render have not been changed.
